Forma y significado. Aplicación de la forma. El estilo indirecto retrocede un tiempo verbal (says → said); los posesivos enfáticos (mine, his) sustituyen a un sustantivo ya mencionado.

Conjunto de modelos. He said that he would arrive late. According to her, the system works well. This file is mine. That password is his. Furthermore, the deadline was extended. Dijo que llegaría tarde. Según ella, el sistema funciona bien. Este archivo es el mío. Esa contraseña es la suya. Además, el plazo se extendió.

Práctica contrastiva. Cambia la persona, el tiempo, el número o el grado de formalidad de cada modelo sin perder su propósito comunicativo.

Comprobación de producción. Di una oración original para cada función: resumir una reunión; escribir un mensaje profesional; explicar un problema técnico. Después escríbela y compara las formas oral y escrita.
