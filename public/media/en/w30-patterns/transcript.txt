Forma y significado. Aplicación de la forma. La pasiva usa be + participio (was approved) y suele añadir by + agente; have/get something done describe una acción que otra persona realiza para ti.

Conjunto de modelos. The report was written by her. I work to improve the service. The law was approved by congress. The data were published yesterday. We had the system repaired last week. El informe fue escrito por ella. Trabajo para mejorar el servicio. La ley fue aprobada por el congreso. Los datos fueron publicados ayer. Hicimos reparar el sistema la semana pasada.

Práctica contrastiva. Cambia la persona, el tiempo, el número o el grado de formalidad de cada modelo sin perder su propósito comunicativo.

Comprobación de producción. Di una oración original para cada función: explicar un proceso; informar acción institucional; decidir si el agente importa. Después escríbela y compara las formas oral y escrita.
